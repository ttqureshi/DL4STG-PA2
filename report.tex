\subsection{Assumptions}

The river layout, the recorded series, and the lack of a travel time are given; A1--A16 are not. A2, A10, A14, and A15 are design choices. The others are assumptions about the river or the record.

\begin{itemize}
\item \textbf{A1.} History is \(H=36\) bins, six hours, ending at issuance. That window has to cover the travel time between neighbouring stations. A longer travel time is seen only through the level it has already produced.
\item \textbf{A2.} The output is six levels at each of S1--S4, at $+10$ through $+60$ minutes, so $\hat Y$ has shape $(B,4,6)$.
\item \textbf{A3.} The archive covers at least one year, including wet and dry periods. Inference still uses only the 36-bin window.
\item \textbf{A4.} On a normal issuance the bin that closes at $t$ has arrived. If it has not, it stays masked and the forecast still goes out.
\item \textbf{A5.} Gauge errors are small beside a rise that matters. There is no separate denoiser.
\item \textbf{A6.} Each rain reading goes in the 10-minute bin that contains its timestamp. An empty bin repeats the last reading and is marked carried, and a carried bin gets no attention weight, so the repeated value is not read as new rain.
\item \textbf{A7.} Releases are piecewise constant between effective times, and the latest already-public announcement is used.
\item \textbf{A8.} S1--S4 and T1 share 10-minute boundaries, so one lag index is the same time at every station.
\item \textbf{A9.} Water moves downstream, and travel time is not distance divided by a constant speed.
\item \textbf{A10.} The target is level, and each series is standardized by its training mean and standard deviation.
\item \textbf{A11.} R1 and R2 are not assigned to reaches; both are tokens, with gauge-to-station distance as a feature.
\item \textbf{A12.} The unmonitored tributary has no gauge, and the S3$-$S2 residual is an extra history channel, zero on the other series.
\item \textbf{A13.} Future rainfall and future levels are not inputs, and a future release is written only when it was announced by issuance.
\item \textbf{A14.} Training uses the same clock: inputs at $t$ obey A13, and the target is the level at $t+\Delta,\ldots,t+6\Delta$.
\item \textbf{A15.} The loss is mean squared error of the standardized level over stations, leads, and the batch, with missing targets left out.
\item \textbf{A16.} Along-river distance is used among the reservoir, S1--S4, and T1, and gauge-to-station distance is straight-line. Neither distance is converted into a travel time.
\end{itemize}

\subsection{Model computations and design justification}

\(\Delta = 10\) minutes. Lag \(\ell = 0,\ldots,H-1\) means time \(t-\ell\Delta\). Lead \(h=1,\ldots,6\) means time \(t+h\Delta\). \(U_{j,i}=1\) when series \(j\) is upstream of series \(i\). Into S1: the release only. Into S2: the release, S1, and T1. Into S3: those plus S2. Into S4: those plus S3. A station is not upstream of itself. \(\phi(d)=-\log(1+d/d_0)\), with \(d_0\) the median static distance. In that formula \(d\) is a distance; elsewhere \(d=64\) is the token width. \(L\) is the token count, not the lookback. \(\lambda_{\mathrm{up}}\) and \(\lambda_{\mathrm{dist}}\) are learned scalars. \(\lambda_{\mathrm{up}}\) biases the score rather than masking it, so a downstream token can still be used if that scalar is small.

A level token carries the standardized level, the mask, and the residual channel. Rain carries standardized rain and its mask. A history release carries actual, schedule, and the actual mask. A future release carries the announced value and the known mask. Each group has its own matrix,
\[
e = W_{\mathrm{group}} x + a_i + b_{\mathrm{time}},
\]
and the token list is \(Z^{(0)}\in\mathbb{R}^{L\times d}\). For block \(n=1,2\),
\[
\mathrm{score}(p,q) = \frac{Q_p\cdot K_q}{\sqrt{d}} + \lambda_{\mathrm{up}} U_{\mathrm{series}(q),\mathrm{series}(p)} + \lambda_{\mathrm{dist}}\phi(d_{q,p}).
\]
A key whose mask is 0 has score \(-\infty\). The block is residual attention plus a residual feed-forward layer of width \(4d\). The query for lead \(h\) at station \(s\) is \(q_{s,h} = W_q[z_{s,0}; e_h; \tau_s]\), where \(\tau_s\) is how many bins since \(s\) last reported. The loss, with \(m_{s,h}(t)=1\) when the target was recorded, is the mean over the batch of
\[
\frac{\sum_{s,h} m_{s,h}(\hat y^{\mathrm{std}}_{s,h}-y^{\mathrm{std}}_{s,h})^{2}}{\sum_{s,h} m_{s,h}}.
\]
One attention block connects every remaining token, so S4 can see the reservoir in one step, and a second block reuses a mix the first has formed. Attention is used instead of a recurrent stack because that path has to exist inside one issuance. With \(L=294\) and \(d=64\), the projections, the scores, and the width-\(4d\) feed-forward layer are about \(2.4\times 10^{7}\) multiply-adds per block. The release is the only upstream series into S1, and T1 enters at S2. Rain and the S3$-$S2 residual reach a station as tokens in the same attention, and they are not rows of \(U\). Both rain gauges are therefore visible at every station, and the distance feature is what tells them apart. What is fixed is the series list, \(U\), and the rule that an announcement enters only if it is already public. What is learned is every matrix, both blocks, the readout, and the two scalars \(\lambda_{\mathrm{up}}\) and \(\lambda_{\mathrm{dist}}\).

\subsection{Operation and exceptional conditions}

\textbf{Missing observations.} A missing value is set to 0 after standardization and its mask to 0, so that token gets score \(-\infty\).

\textbf{Delayed observations.} A bin that has not arrived by \(t\) is missing, and the readout sees \(\tau_s\), the bins since that station last reported. The forecast is issued on the 10-minute mark and does not wait.

\textbf{Announced future releases.} The latest announcement with announcement time at or before \(t\) and effective time in the lead bin has known mask 1, and if none exists the mask is 0. A published flat schedule has mask 1, so ``no change'' is different from ``no announcement.''

\textbf{Scheduled versus actual releases.} History bins carry the recorded actual and the announced schedule, and the future channel is only the schedule. The actual release after \(t\) is not an input. The next issuance sees it in the history.

Each issuance is one forward pass of two attention blocks over 294 tokens of width 64 and 24 queries, which fits between the ten-minute bins.

\subsection{Uncertainty, limitations, and additional information}

The readout is a point forecast. The loss is mean squared error, so there is no variance and no quantile. An operator should read a large rise as the warning, and should not read the number as a confidence interval.

The unmonitored tributary can raise S3 and S4 with no trace in S2, T1, the release, or R1 and R2 until that water reaches S3. I use the S3$-$S2 residual and S3's history, and S4 reads those tokens in one attention block. That residual is not a measured inflow: the gauges have different datums, and the same-time difference ignores the travel lag, so the block learns a mapping from the channel. Inflow that has not reached S3 by \(t\) is still unseen.

A changing travel time can put a peak in the wrong 10-minute bin. The model attends over every lag in the \(H=36\) window, with a separate query for each of the six leads, and uses distance as a feature. A travel time longer than \(H\), or a speed change during the future hour, is still unseen.

A gauge on the unmonitored tributary would be a ninth series and would show that inflow before it reaches S3. Travel times at a low stage and a high stage would check whether \(H=36\) cuts off ordinary waves, and a catchment plus an error bar would fix which gauge belongs to which reach and how the loss weights the instruments. S1--S4 are still forecast without those extras.

\textbf{Q2.3.} Model A's one-step reach is 8 original pixels. \texttt{pixel\_unshuffle(4)} leaves a \(16\times 16\) grid whose neighbouring cells are 4 original pixels apart, centre to centre. The fold, the \(1\times 1\) head, and \texttt{pixel\_shuffle} do not move information to another cell. Each \(3\times 3\) kernel moves one folded cell. Inside one step the new input passes through layer 1 and then through layer 2, which reads layer 1's new hidden state. That is two cells, \(2\times 4 = 8\) original pixels. The previous hidden state of layer 1 travels the same two kernels. The previous hidden state of layer 2 travels only one, which is 4 original pixels. The longest path is \(u_{\tau}\rightarrow\) layer-1 \(3\times 3\rightarrow h^{(1)}_{\tau}\rightarrow\) layer-2 \(3\times 3\rightarrow\hat x_{\tau+1}\).

\subsection{Q2.5}

This answer was committed as \texttt{10cb5f4} at 14:35 on 27 October 2026, before the mirror, rotation, and speed tests. It is unchanged.

Model A will not pass the mirror test. Its one-step reach is 8 original pixels, which is a statement about how far a \(3\times 3\) convolution can move information, not about reflection. The filters are ordinary convolutions, with no mirrored copy of the weights. Figure~1(a) is not symmetric under a horizontal flip: reflecting the measured flow sends \(\theta\) to \(180^{\circ}-\theta\) and moves 13.2\% of the 103{,}050 kept pixels into a different \(20^{\circ}\) bin. A mirrored digit is also a different glyph. Both the direction balance and the appearance sit outside the \(1\times\) training sample, so \(f(M(X))\) should disagree with \(M(f(X))\) and with \(M(Y)\).

Model A will not pass the rotation test, and rotation should be worse than mirroring. A \(90^{\circ}\) anticlockwise turn changes the glyph further than a left-right flip, and on these same pixels it reassigns 20.0\% of the kept flow into a different bin. Nothing in the two-layer ConvLSTM ties a filter to its quarter-turn.

It should break at \(3\times\), and \(2\times\) should already be strained for the faster digits. The median consecutive-frame speed is 3.32 pixels per frame, inside the 8-pixel reach. Twice that median is 6.64, still under 8 but close. The 99th percentile at \(1\times\) is 4.67, which becomes about 9.3 at \(2\times\) and is already past the reach. Three times the median is 9.95, beyond 8.

\textbf{Q2.12.} Model D's one-step reach is 16 original pixels, against Model A's 8. A \(3\times 3\) kernel with dilation 2 reads offsets \(-2,0,+2\), so one layer moves 2 folded cells, which is 8 original pixels. The new input passes through both layers, and layer 2 reads layer 1's new hidden state, so the longest path is 4 folded cells, \(4\times 4 = 16\). The path is \(u_{\tau}\rightarrow\) layer-1 dilated \(3\times 3\rightarrow h^{(1)}_{\tau}\rightarrow\) layer-2 dilated \(3\times 3\rightarrow\hat x_{\tau+1}\). The \(1\times 1\) head and the shuffles add nothing. The previous state of layer 2 travels only one dilated kernel, which is 8 original pixels. One path moves an even number of folded cells, 0, 2, or 4, so an odd offset is reached only by combining paths. The reach is the longest path. Dilation adds no weights; a \(5\times 5\) kernel on both layers would pass the cap of 721{,}176.

\subsection{The final model}

Table 5 supports D+B. Model B cut the rotation gap without moving \(E(5)\), and Model D's rotation gap (0.00181) was still larger than its mirror gap. D+B is Model D trained with both the speed draw and one shared group element on each window. Its \(E(5)\) is 0.0285 (0.0287, 0.0282), slightly under D. Its gaps are \(C_M=7.53\times10^{-4}\) and \(C_R=9.89\times10^{-4}\), with \(E_M=E_R=0.0285\). Its \(E(2)\) is 0.0261, 0.0290, and 0.0313 at \(1\times\), \(2\times\), and \(3\times\). The speed gains survive. The final model is that network wrapped as
\[
\bar f(X)=\frac{1}{8}\sum_{g\in G} g^{-1}\big(f(g(X))\big).
\]
For any \(h\in G\), right multiplication by \(h\) permutes \(G\). The group element only rearranges pixels, so it commutes with the average and factors out, and \(\bar f(h(X))=h(\bar f(X))\). Since \(M\) and \(R\) are in \(G\), \(C_M=C_R=0\) exactly. The measured gaps are the floating-point residual.
